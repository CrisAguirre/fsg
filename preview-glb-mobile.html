Cómo usar esta página

En el PC ejecuta npm run dev -- --host y abre en el móvil http://IP-DEL-PC:5173/preview-glb-mobile.html (misma red Wi-Fi). Ajusta Rot X/Y/Z y Vertical hasta que el puente quede sobre la nariz y las patillas salgan hacia las orejas. Usa Zoom para corregir el tamaño relativo (1.00× = tamaño calculado con las medidas de la montura). Arrastra el modelo para mirarlo desde otro ángulo. Los cambios se guardan solo en este navegador; “Ver JSON” genera el bloque para pegar en public/glasses/manifest.json.
